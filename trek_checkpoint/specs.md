## Spares & wear parts

### Chain — SRAM Flattop 12-speed
All SRAM 12-speed **Flattop** road/gravel chains (Apex / Rival / Force / RED **D1**) are
cross-compatible — same construction, differ only in finish, pin type, weight, price.
Sold in **120 links**, each with **one single-use Flattop PowerLock**.

| Tier | Model | Notes |
|---|---|---|
| Apex D1 | **CN-APX-D1** | polished grey; identical build to Rival/Force — fine as the emergency spare |
| Rival D1 | CN-RIV-D1 | silver |
| Force D1 | CN-FRC-D1 | hard-chrome inners — best wear + corrosion resistance for wet/gritty gravel |
| RED D1 | CN-RED-D1 | hollow pins, lightest; not worth the money here |

- **Must say "Flattop" + "12-speed."** NOT SRAM Eagle / T-Type (MTB), NOT 11-speed, NOT Shimano.
- Practical plan: run **Force D1** as the working chain, keep an **Apex D1 (CN-APX-D1)** as the bag spare.
- Also buy 2–3 spare **Flattop PowerLocks** (the box link is used at install; it's single-use).
- Chain wear: use a **Flattop-compatible** gauge — some standard 12s gauges misread Flattop. Replace at ~0.5% to save the 10–44 XDR cassette.
- Sizing (1× 40T / 10–44): expect ~114 links after sizing; the 120L chain covers it. Size by SRAM's big-big + 4 links method.

### Front-brake pads — SRAM road, 2-piece caliper ("AXS / Level")
Rival eTap AXS HRD calipers take the **2-piece caliper road pad** (centered mounting tab).
Same pad as Force AXS / RED AXS HRD / Apex AXS / Level. **Not** the newer "Monoblock" shape.

**Running organic / resin** — wears faster in grit but stops fine, and no rotor
deglaze/marriage hassle. Stock up on 2+ sets.

| Compound / backing | SRAM p/n | Note |
|---|---|---|
| Organic / steel — "quiet" | **00.5318.024.001** | the default; buy these |
| Organic / aluminium — "light" | 00.5315.035.020 | optional — lighter, sheds heat better |
| Sintered / steel — "powerful" | 00.5315.035.010 | *not currently used* — a compound switch means deglazing or replacing the rotors first |

- Aftermarket in the same fit: SwissStop Disc 32 RS/E, Jagwire Pro, Galfer, Kool Stop.
- Replace before pad material drops below ~0.7 mm. New pads → bed in with 20–30 progressive stops.

### Other consumables to keep on hand
- Tubeless sealant + spare valve cores; a spare 700×35–45 tube
- SRAM DOT 5.1 (brake bleed) — see SKILLS §4
- Bontrager gel/cork bar tape; brake/shift housing is minimal (AXS = rear brake hose only)
- Spare AXS battery (shared: derailleur / dropper)
