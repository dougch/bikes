# Cross-bike parts compatibility

Which spares and wear parts can be shared between bikes, and which only look like they can.
Per-bike part numbers, sizing and service notes live in each bike's `specs.md`. This page
only covers where the bikes overlap.

| Bike | Drivetrain | Brakes | Wheels |
|---|---|---|---|
| Trek Checkpoint | SRAM AXS 1x12, XDR 10–44 | SRAM hydraulic disc, flat mount | 700c + 650b, 12x100 / 12x142 thru-axle, tubeless |
| Cervelo S2 | SRAM AXS 2x12, XDR 10–33 | Rim, cable caliper | 700c road (models TBD) |
| Santa Cruz Stigmata | SRAM Force 1x10, HG 12–32 / 11–32 | Front BB7 disc, rear cantilever | 700c, 100 QR front / 130 QR rear, tubeless (DIY) |
| LeMond Poprad Disc | SRAM Force 2x10, HG 11–36 | BB7 mechanical disc, front and rear | 700c, 130 QR rear, not tubeless |

## Shared parts

| Part | Fits | Notes |
|---|---|---|
| SRAM Flattop 12sp chain (Apex/Rival/Force/RED D1) | Checkpoint, S2 | 120L covers both, but size each bike's chain separately (1x vs 2x). An Apex D1 is a fine spare for either. |
| Flattop 12sp PowerLock | Checkpoint, S2 | Single-use. Not interchangeable with 10sp or Eagle/T-Type links. |
| Flattop-compatible chain wear gauge | Checkpoint, S2 | Some standard gauges misread Flattop. |
| SRAM AXS battery | Checkpoint (RD, Reverb AXS XPLR), S2 (RD, FD) | One battery type for every AXS derailleur and the dropper. A single charged spare covers both bikes. |
| CR2032 coin cell | Checkpoint (shifters, dropper controller), S2 (shifters) | Used in AXS shifters and controllers. |
| 10sp chain (KMC X10, SRAM PC-1050/1070) | Poprad, Stigmata | A 116L chain covers both. Poprad (2x, 11–36, long cage) needs more links than Stigmata (1x 39T, 12–32). |
| 10sp quick link (KMC 10sp Missing Link) | Poprad, Stigmata | Match the speed: 10sp only. |
| Avid BB7 pads | Poprad (front + rear), Stigmata (front) | BB7 Road and Mountain use the same pad. Three calipers total, so buy in multiples. |
| Front wheel | Poprad, Stigmata | Both 29er disc, BB7. Swap confirmed working; quick way to put slicks on the Stigmata. |
| Road shift inner cable + 4 mm housing | Poprad, Stigmata | Mechanical SRAM Force 10sp (Exact Actuation) on both. |
| Road brake inner cable + 5 mm housing | S2, Stigmata, Poprad | Rim calipers, cantilever straddle, BB7 Road. |
| 700×35–45 tube | Checkpoint (700c set), Stigmata, Poprad | Check valve length against each rim. Not for the S2 (road width) or the Checkpoint 650b set. |
| Tubeless sealant, Presta valve cores | Checkpoint, Stigmata | Poprad isn't tubeless yet. |

## Looks shared but isn't

| Part | Why not |
|---|---|
| 12sp cassettes (Checkpoint ↔ S2) | Both XDR, but the S2's 2x road RD can't run the Checkpoint's 44T cog. |
| Rear wheels (Poprad ↔ Stigmata) | Both 130 mm QR with HG freehub, but Poprad is disc and Stigmata is rim/cantilever. |
| Disc pads (Checkpoint ↔ BB7 bikes) | Checkpoint uses SRAM 2-piece road hydraulic pads, a different shape from BB7. |
| Rim pads (S2 ↔ Stigmata rear) | Road caliper vs cantilever. Kool Stop Salmon comes in both, but the pads aren't the same part. |
| Bottom brackets | All four differ: T47 DUB Wide (Checkpoint), BSA DUB, unconfirmed (S2), BSA for an FSA crank, type TBD (Stigmata), Hollowtech II BBR60 (Poprad). |
| Brake fluid | Only the Checkpoint is hydraulic (SRAM DOT 5.1). |
