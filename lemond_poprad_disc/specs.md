# LeMond Poprad Disc — size 56cm

Steel cyclocross/touring frame (True Temper OX Platinum tubing, TIG-welded, disc-specific
dropouts). "Disc" in the model name reflects that this bike shipped from the factory
with a front disc-compatible carbon/aluminum fork — a **Bontrager** (branding visible on
the fork itself; no model name legible). This is the stock, original fork and has never
been replaced. Currently built as a **2x10 SRAM Force** commuter/gravel bike.
Long-serving bike, now due for a full rebuild. Model year 2005 —
LeMond's disc-specific Poprad ran roughly mid-2000s through the early 2010s; narrow it
down from the True Temper "OX Platinum" tube decal and the disc dropout style (see
Sources).

## 3. Stock specification (LeMond Poprad Disc, for reference — verify against this bike)

- **Frame:** True Temper OX Platinum steel, handbuilt (Wisconsin per period reviews), disc-specific dropouts
- **Fork:** **Bontrager**, carbon/aluminum, disc-specific — **confirmed stock/original,
  never replaced** (branding is visible directly on the fork; exact model name is not
  legible/confirmed — period reviews cite a "Bontrager Switchblade Elite," which may or
  may not be this exact fork). Unlike the Stigmata, which had its stock cantilever fork
  thrown away and replaced with an aftermarket Winwood disc fork
  (`santacruz_stigmata/specs.md` §3), **this bike's disc fork has always been stock** —
  no fork swap has happened here. Winwood is not part of this bike at all.
- **Brakes:** front disc, stock — matches the "Poprad **Disc**" name and the factory
  disc-specific fork/dropouts. Avid BB7 mechanical disc was common on these builds
  (matches the current front caliper — see §2); worth confirming the rear caliper too.
- **Wheels:** 700c (622 mm BSD)
- **Stock tire width:** ~34 mm (period spec — well under this bike's measured clearance)
- **Stock groupset (varies by year):** Shimano 105 was common; SRAM Force 2x10 on this
  bike may be an upgrade/alternate spec — worth confirming against the frame's model year

### Geometry — a sizing note first

LeMond conventionally sized frames in **odd centimeters** (49/51/53/55/57/59/61) — there
is no "56cm" in that scheme. The most likely explanation: **56cm is this frame's
effective top tube**, not its seat-tube size, and the frame itself is the **55cm**
size. That matches a 2005 Poprad 55cm listing found directly (not a scraped aggregator):

| Measure | Value | Source |
|---|---|---|
| Seat tube (C-T) | 55 cm | 2005 Poprad 55cm listing |
| Effective top tube | 56 cm | same |
| Actual top tube | 56 cm | same |
| Head tube length | 11.5 cm | same |
| Wheelbase | 115 cm | same |
| Standover | 82 cm / 32 in | same |
| Reach | 36 cm | same |
| Stack | 56 cm | same |

**Still unconfirmed for this specific size/year:** head tube angle, seat tube angle,
chainstay length, BB drop, fork rake. Generic Poprad Disc review figures exist (~72.5°
parallel head/seat angles, ~45 mm fork rake, ~74 mm BB drop, ~430 mm chainstay), and a
~1025 mm review-quoted wheelbase is close to the 115 cm above, but none of that has been
confirmed as matching this exact size — treat those numbers as indicative only until
pulled from the frame or a size-matched chart.

## 4. Planned upgrade path ("To Spec")

- **New wheelset, tubeless.** Rear built around a **Force 22 (2x10/11-speed) disc QR**
  hub — e.g. the Mavic Ksyrium Pro Disc rear (QR, Centerlock, SRAM/Shimano 10/11-speed)
  — or a custom build (see §5).
- **Groupset: SRAM Force22, hydraulic, 2x11-speed**, 11-32 cassette.
- **Shorter crank arms — 165 or 170 mm** — direct mitigation for the toe-overlap issue
  (shorter crank = pedal/toe sits closer to the BB axis, more clearance from the front wheel).
- **New chain.**
- **New BB** — English-threaded, Force22-compatible (this bike already has an
  English-threaded shell per the 2025 Ultegra BBR60 install, so continuity is straightforward).

## 5. Long-term plan

- **Summer 2027:** rebuild the Poprad as a resto-mod (modern brakes/drive-train, but as close to stock otherwise)
- **AXS Rival is a dead end on this frame.** It requires a through-axle frame — this is QR,
  and SRAM doesn't make QR hubs for AXS Rival. Spreading the rear to 135–142 mm doesn't
  fix it either, because the only hubs available at that spacing are through-axle, which
  would require re-dishing/welding the frame — not worth it on a steel commuter build.
- **SRAM Force22 is the last realistic upgrade path for this bike:** hydraulic brakes,
  mechanical (cable) shifting, and it's still available with **QR** hubs and broad
  freehub compatibility.
- **Wheel shopping:** look for **Shimano HG freehub** compatibility — needs **135 mm
  rear spacing**, but should support disc + QR + 11-speed cassettes together. Example
  candidate: https://www.modernbike.com/product-2126376372
- **Custom wheel build options:**
  - https://www.cascadiawheelco.com/
  - https://shotsandsprockets.com/custom-bike-builds-frames/
- **Tires:** tubeless **WTB Barlow Pass**, front and rear.
- **Fenders:** media-blast and anodize/repaint; add a proper rear-fender mount so it
  stops sliding (current fenders are DIY + 3D-printed and fit well).
